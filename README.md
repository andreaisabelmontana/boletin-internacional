# Boletín Internacional · Bogotá

Interfaz en GitHub Pages. GitHub Actions consulta el catálogo oficial de oportunidades cada hora, conserva las fichas en JSON y publica la web. Los horarios de Actions pueden retrasarse. Una consulta fallida conserva el último catálogo publicado y deja el error en Actions.

Búsqueda, filtros, fechas de cierre, fichas desplegables, exportación CSV y guardados personales en el navegador. Los guardados no se comparten entre dispositivos. No hay administración ni base de datos privada en esta versión.

La página muestra la fecha de la última recolección exitosa. La actualización consulta actualmente el Boletín de Oferta Internacional de Bogotá; no rastrea todas las fuentes internacionales.

Identidad y recursos institucionales procedentes del sitio oficial. Componentes adaptados de ScholarTrack (MIT), véase THIRD_PARTY_NOTICES.md.
